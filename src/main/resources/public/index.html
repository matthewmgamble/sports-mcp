sports-mcp

Connect an MCP client

Streamable HTTP endpoint, no sign-up:

https://YOUR-HOST/mcp

Claude Code:

claude mcp add --transport http sports https://YOUR-HOST/mcp

Other clients: add a remote MCP server with the URL above.

Tools

sports_get_live_scoresGames in progress now, with score, period and clock
sports_get_gamesA league's or team's games for a day or date range
sports_get_team_scheduleA team's last 3 results and next 5 games
sports_get_gameOne game by id
sports_list_teamsFind teams by name, city or nickname ("leafs")
sports_list_leaguesLeagues covered

REST

curl "https://YOUR-HOST/api/v1/games/live"
curl "https://YOUR-HOST/api/v1/teams/leafs/schedule"
curl "https://YOUR-HOST/api/v1/games?league=nfl&date=today&tz=America/Toronto"

Full reference: OpenAPI 3.1. Every response is {data, meta}; meta.isStale tells you when upstream data couldn't be refreshed.

Fair use

Anonymous use is rate-limited per client (about 60 requests a minute). Scores are near-live and can trail the broadcast by several seconds. Want to run your own? It's a single Docker container: github.com/matthewmgamble/sports-mcp.
